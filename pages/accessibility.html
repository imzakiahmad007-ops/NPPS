Accessibility Statement

Our Commitment to Inclusive Web Design

1. Commitment to Accessibility

New Pioneer Public School is committed to making our website accessible to all users, including those with disabilities. We strive to follow Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards and provide an inclusive experience for everyone.

2. Accessibility Features

Our website includes the following accessibility features:

  • Keyboard Navigation: All interactive elements are accessible via keyboard
  • Screen Reader Support: Content is structured for screen reader compatibility
  • Semantic HTML: Proper heading hierarchy and semantic markup
  • Color Contrast: Text maintains sufficient contrast ratios for readability
  • Readable Fonts: Clear, sans-serif fonts with adequate sizing
  • Alt Text: Descriptive alt text for all meaningful images
  • Form Accessibility: Properly labeled form fields with error messages
  • Skip Navigation: "Skip to main content" link at the beginning of the page
  • Reduced Motion Support: Respects prefers-reduced-motion user preference
  • Mobile Accessibility: Responsive design works on all device sizes
  • Focus Indicators: Clear visual focus indicators for keyboard navigation
  • ARIA Labels: Appropriate ARIA attributes where necessary

3. Browser & Assistive Technology Support

Our website has been tested with the following assistive technologies and browsers:

  • NVDA (NonVisual Desktop Access)
  • JAWS (Job Access With Speech)
  • VoiceOver (macOS/iOS)
  • Narrator (Windows)
  • Chrome, Firefox, Safari, Edge (latest versions)
  • Mobile browsers (iOS Safari, Chrome Mobile)

4. Known Accessibility Limitations

While we strive for full accessibility, some third-party content may have limitations:

  • Embedded maps may have limited screen reader support
  • PDF documents linked from the site may vary in accessibility
  • Some third-party services embedded on the site may have limitations

5. Accessibility Conformance

We aim to conform to WCAG 2.1 Level AA standards. However, full manual testing with multiple assistive technologies requires ongoing expert review. Please note that accessibility is an ongoing process, and we continuously work to improve our website.

6. How to Navigate This Website

Using Keyboard:

  • Tab: Move forward through interactive elements
  • Shift + Tab: Move backward through interactive elements
  • Enter: Activate buttons and links
  • Arrow Keys: Navigate within menus and select options
  • Esc: Close open menus

Using Screen Readers:

  • All page sections are properly labeled
  • Navigation landmarks are clearly marked
  • Form fields have associated labels
  • Links have descriptive text
  • Images have alternative text descriptions

7. Browser & Device Settings

You can customize your viewing experience using browser settings:

  • Increase font size in your browser settings
  • Enable high contrast mode in your operating system
  • Use browser zoom (Ctrl/Cmd + Plus key)
  • Enable text resizing in browser preferences
